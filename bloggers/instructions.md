# UX-рефактор: инструкция по дизайну и кликам

## 0. Общая концепция сейчас vs. после

| Сейчас | После |
|--------|-------|
| Горизонтальная nav-полоска — 5 пунктов наравне | Левый sidebar с иконками + подписями |
| Header + nav — 2 отдельных полосы | Объединить в один топбар или sidebar |
| Кнопка "создать" — в правом верхнем углу таблицы | Фиксированная FAB или кнопка в sidebar-секции |
| Детали записи — новая страница | Sliding drawer справа (без потери контекста) |
| Модалы — по центру экрана | Drawer справа (mobile: bottom sheet) |

---

## 1. Навигация

### Текущая боль
- Горизонтальный nav скроллится на узких экранах → пользователь не видит активный пункт
- "Интеграции" и "Контрагенты" — главное; "Дашборд", "Задачи", "Доставки" — второстепенное
- Нет иерархии, все пункты одинаковые

### Решение: левый sidebar (коллапсирующий)

```

│ CASHER   [avatar: SE]              🔔 ⚙ │  ← топбар (40px)
├──────┬──────────────────────────────────┤
│  ≡   │                                  │
│      │                                  │
│ [📋] │  контент страницы                │
│ Инт. │                                  │
│      │                                  │
│ [👥] │                                  │
│ Конт │                                  │
│      │                                  │
│ [📦] │                                  │
│ Дост │                                  │
│      │                                  │
│ [✅] │                                  │
│ Зада │                                  │
│      │                                  │
│ ─────│                                  │
│ [📊] │                                  │
│ Даш  │                                  │
│      │                                  │
│ [📄] │                                  │
│ Отч  │                                  │
│      │                                  │
│ [⚙]  │                                  │
│ Адм  │                                  │
└──────┴──────────────────────────────────┘
```

- Ширина collapsed: 56px (иконка), expanded: 200px
- Активный пункт: яркая полоска слева + accent-цвет
- Топ-группа: рабочие разделы; нижняя группа: аналитика + настройки
- Mobile: bottom tab bar (5 пунктов максимум)

**Клик по иконке → разворачивает sidebar (если collapsed) + переходит на страницу**

## 2. Страница «Интеграции» (главная рабочая)

### Текущая боль
- Много фильтров горизонтально → перегруженность
- Клик по строке → новая страница → теряешь скролл и фильтры
- Нет быстрого статус-чейнджа без открытия карточки

### Решение: таблица + drawer

```
┌─────────────────────────────┬─────────────────┐
│ ИНТЕГРАЦИИ      [+ Создать] │  ←drawer закрыт │
│─────────────────────────────│                 │
│ [Поиск...]  [Статус ▼] [Период ▼] [Блогер ▼] │
│─────────────────────────────│                 │
│ ● СОГЛАСОВАНО  @username  … │                 │
│ ● ГОТОВО       @blogger2  … │                 │
│ ● ОПУБЛИКОВАНО @blog3     … │                 │
│ …                           │                 │
└─────────────────────────────┴─────────────────┘

После клика на строку:
┌──────────────────────┬──────────────────────────┐
│ таблица (затемнена)  │ [×]  Интеграция #123      │
│                      │ ──────────────────────    │
│                      │ Статус: [СОГЛАСОВАНО ▼]   │
│                      │ Блогер: Петя Иванов        │
│                      │ Дата выхода: 20 мая        │
│                      │ Бюджет: 15 000 ₽           │
│                      │                            │
│                      │ [Задачи] [Доставки] [Лог] │
│                      │ …                          │
│                      │ [Удалить]    [Сохранить]   │
└──────────────────────┴────────────────────────────┘
```

- **Одиночный клик строки** → открывает drawer справа (анимация 200ms)
- **Escape / клик вне drawer** → закрывает
- **Смена статуса** прямо в drawer — select без сохранения (auto-save при change)
- **Кнопка "+ Создать"** — верхний правый угол страницы, всегда видна

### Фильтры
- Оставить 3-4 фильтра в одну строку: поиск + статус + месяц + блогер
- Остальные (ниша, категория, сотрудник) — кнопка "Ещё фильтры" → dropdown/popover
- Активные фильтры — чипсы под строкой фильтров с крестиком

## 3. Страница «Контрагенты»

### Текущая боль
- Создание — модал поверх списка (ок, но форма длинная — нужен скролл в модале)
- В таблице нет быстрого доступа к соцсетям
- Детальная страница блогера — отдельный URL, нет breadcrumb

### Решение

```
КОНТРАГЕНТЫ                          [+ Добавить]
[Поиск] [Статус ▼] [Ниша ▼] [Категория ▼]

┌──────────────────────────────────────────────┐
│ ● АКТИВНЫЙ  Петя Иванов  ★8.4  Лайфстайл  … │  ← клик → drawer
│ ● ПАУЗА     Маша Bloger  ★6.0  Фитнес     … │
└──────────────────────────────────────────────┘
```

**Drawer контрагента** содержит вкладки:
```
[Профиль] [Интеграции (12)] [Доставки (3)] [Товары (5)]
```

- Вкладка "Профиль" → редактируемые поля, inline edit (клик → input)
- Вкладка "Интеграции" → мини-таблица интеграций этого блогера
- URL не меняется при открытии drawer, но поддерживает deep-link: `/contractors?id=xxx`

**Кнопка "+ Добавить"** → drawer справа (не модал-поверх), форма с прокруткой

---

## 4. Страница «Доставки»

### Текущая боль
- Таблица широкая, scroll-индикатор есть, но неочевиден
- Статус доставки нельзя менять без открытия карточки

### Решение
- Аналогично интеграциям: строка → drawer
- В таблице добавить колонку с inline-кнопкой статуса: кликабельный badge `[ОТПРАВЛЕНО ▼]` → dropdown без открытия drawer
- Группировать по месяцам с collapsible-заголовком

---

## 5. Страница «Задачи»

### Текущая боль
- Список задач без группировки
- Чекбокс есть, но нет визуального деления "просрочено / сегодня / предстоящее"

### Решение

```
ЗАДАЧИ

⚠ ПРОСРОЧЕНО (3)
  ☐ Подтвердить выход @blogger — 10 мая
  ☐ …

◉ СЕГОДНЯ (2)
  ☐ Прислать тз @bloger2 — 15 мая
  ☐ …

○ ПРЕДСТОЯЩИЕ (8)
  ☐ …

✓ ВЫПОЛНЕНО (показать/скрыть)
```

- Клик на задачу → drawer с деталями (к какой интеграции, контрагент)
- Чекбокс = моментальный toggle, без drawer
- Цвет строки: красный = просрочено, нормальный = ок

## 6. Дашборд

### Текущая боль
- Дашборд — отдельный экран с суб-навом (3 вкладки)
- Метрики и графики разбросаны

### Решение
- Убрать суб-нав, сделать один скроллящийся дашборд
- Структура сверху вниз:

```
[Выберите месяц ◄ Май 2026 ►]

┌────────┬────────┬────────┬────────┐
│ Интег. │ Охват  │ Бюджет │  CPM   │  ← KPI-карточки
│   12   │  240K  │ 180K₽  │ 750₽   │
└────────┴────────┴────────┴────────┘

[Bar chart охватов по дням]

┌─────────────────────┬───────────────────┐
│ Топ-5 блогеров      │ Промокоды (Δ)     │
│ по охвату           │ этот месяц        │
└─────────────────────┴───────────────────┘

[Таблица интеграций за месяц — condensed]
```

## 7. Создание записей — единый паттерн

Везде одинаково:
1. Кнопка "+ Создать/Добавить" — верхний правый угол страницы
2. Клик → **drawer справа** с формой (не модал по центру)
3. Форма: обязательные поля сверху, опциональные снизу за `▸ Дополнительно`
4. Кнопки в drawer: `[Отмена]` `[Создать]` — прибиты к низу drawer
5. После создания: drawer закрывается, строка появляется в таблице (highlight на 2 сек)

## 8. Мобильные приоритеты

| Элемент | Мобильное поведение |
|---------|---------------------|
| Sidebar | Bottom tab bar (5 иконок) |
| Drawer | Bottom sheet (80% высоты) |
| Таблица | Горизонтальный скролл + sticky первая колонка |
| Фильтры | Кнопка "Фильтры" → full-screen sheet |
| FAB "+ Создать" | Фиксированный в правом нижнем углу |

---

## 9. Единые UI-правила

- **Все статусы** — кликабельные badge с dropdown (не нужно открывать карточку)
- **Все денежные значения** — правое выравнивание, tabular-nums
- **Пустые состояния** — иллюстрация + текст + кнопка "создать первый"
- **Bulk-действия** — чекбоксы в таблице появляются при hover первой строки → toolbar сверху с [Изменить статус] [Экспорт]
- **Undo-баннер** — после удаления внизу экрана "Удалено. Отменить" (5 сек)
- **Auto-save** в drawer — поля сохраняются при blur, кнопка "Сохранить" только для подтверждения
